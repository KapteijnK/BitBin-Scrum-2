### Over het project en de opdrachtgever

TotalCode B.V. is een software development bedrijf dat zich alleen bezighoudt met de allernieuwste technieken. Over deze technieken is vaak nog weinig te vinden op internet,  daarom vinden ze het belangrijk dat kennis over deze technieken intern gedeeld wordt. Ze merken dat dit weinig gebeurt, omdat het lastig is om kennis en code met elkaar te delen. Veel bestaande oplossingen kunnen ze niet gebruiken omdat ze de code en kennis wel geheim willen houden.
Om het delen van code makkelijker te maken wil TotalCode B.V. graag een eigen variant van pastebin.com voor intern gebruik: de BitBin.

### Eisen en wensen (MoSCoW)

**MoSCoW** is een afkorting waarbij de hoofdletters staan voor:

**M** - Must have: *Deze eisen moeten in het eindresultaat terugkomen. Zonder*
*deze eisen is het product niet bruikbaar.*

**S** - Should have: *Deze eisen zijn zeer gewenst, maar zonder is het*
*product wel bruikbaar.*

**C** - Could have: *Deze eisen zullen alleen aan bod komen als er tijd*
*genoeg is.*

**W** - Won't have (now): *Deze eisen zullen in dit project niet aan bod*
*komen, maar kunnen in de toekomst bij een vervolgproject aan bod komen.*

Must have
- : Code opslaan
- : Random link voor het delen van de code
- : Code highlighting voor PHP
- : Code highlighting voor HTML
- : Code highlighting voor CSS
- : Code highlighting voor SQL
- : Code highlighting voor JS
- : Code highlighting voor C#

Should have
- : Favoriete code opslaan in de browser
- : Categorie toevoegen aan de code/kennis

Could have
- : Admin pagina voor het aanpassen van de opgeslagen code/kennis
- : Preview voor md files

Won't have (now)
- : login systeem
- : vervaldatum
